# Windows Implementation Plan

> For agentic workers: use subagent-driven-development for isolated modules and review, continuing in this session.

**Goal:** 可构建安装的 Windows x64 奶灰桌宠。
**Architecture:** Electron 主进程管理窗口、设置、额度；沙箱 renderer 播放透明动作，独立领域规则可由 Node 测试。
**Tech Stack:** Electron 44、Node 测试、electron-builder NSIS、VP9 alpha。
**Spec:** docs/superpowers/specs/2026-09-19-windows-design.md

## Global Constraints
- Windows 10/11 x64。保留 Swift 应用。
- 只有明确连接后读账号；不导出凭证。
- 小横版卡片位于猫下方，点击外部关闭。
- 未实测项目不得声称通过。

## Task 1: 额度领域及 Windows 适配
- [ ] 在 Windows/test/quota.test.cjs 写 80/100 跨越、重复采样、账号切换、重置、鉴权与失败测试，先执行 `node --test Windows/test/quota.test.cjs` 验证红灯。
- [ ] 实现 Windows/src/quota.cjs，exports QuotaService、parseCodex、parseClaude、ReminderTracker。服务连接和读取接口供主进程调用，严格限制固定端点、请求大小和超时。
- [ ] 重跑测试并复核 Windows 数据源差异。
