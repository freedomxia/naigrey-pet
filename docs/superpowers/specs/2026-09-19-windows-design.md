# 奶灰 Windows 首版

用户已批准 Windows 10/11 x64 桌宠、互动动作、下方横版额度卡片、点击外部收起、Codex/Claude 额度提醒及安装包、托盘、开机启动。

采用独立 Electron 程序，放在 Windows/。保留现有 Swift 应用。透明置顶小窗使用 Canvas / 视频合成；从原 HEVC alpha 在 macOS 解码转换 VP9 alpha，并保留动作锚点。动作按入口、循环、出口播放，预载后切换，不把几个不连续姿态当作动画。

主进程读本地账号、请求固定 HTTPS 额度接口；renderer 无 Node 权限。默认不连接账号，用户点击连接后才读取凭证。凭证不传 renderer、不写设置、不进入日志。明确报告不可用和过期，禁止虚假值。演示独立开关。

额度域模型与阈值、重置检测按现有 Codenotch 规则移植；Windows 登录来源与 macOS Desktop 缓存不同，准确记录差异，不宣称未验证的完全一致。自动动作仅由确认事件触发。Windows 凭证续期首先由原客户端负责。

使用 NSIS 用户级安装包，Windows CI 执行测试与打包。首版未有代码签名证书。单元测试覆盖鉴权边界、限流、阈值去重、重置、动作路径、显示器边界；本机可测渲染和交互，Windows CI 可测启动，真实 Windows 动画与账号验收单独标记。
