## 后续 Mac 对齐改动（尚未在目标机器目视确认）

对照 [行为对照](mac-parity.md) 逐项补齐后，以下改动只有 Node 测试和本机检查覆盖，界面效果需要在 Windows 上目视确认：

- 额度卡片的三档配色、灰色未知条、提供方状态行、`isExtra` 分级与「另有 N 个额度窗口」。
- 设置页的预览气泡、状态名、「最近确认 / 历史记录」区分、extra 前缀、单个暂停/恢复切换。
- 气泡改为包住文字并贴头顶、字号随猫缩放、带阴影与弹入；AI 徽章随猫尺寸移动。
- 托盘菜单条目与 Mac 对齐，猫咪大小改为四档中文名、默认「小巧」。0.2.0 曾提供的 140 已不在可选值内；保存过 140 的设置会迁移到最接近的 130（视觉落差 7%）而不是回落到默认的 100（落差 29%）。**此迁移在 0.2.2 才生效——已经运行过 0.2.1 的机器，140 这个值已被覆写为 100，无法追回。**
- 重置时间默认改为绝对日期（原默认倒计时）。
- 走动与拖动按绘制轮廓约束，猫能走到屏幕边缘。
- 更新要求发布者 Ed25519 签名（预览渠道保持开启，不影响现有发布的更新提示）。**签名流程已在本机用真实发布密钥演练：公钥配对、验签、篡改拒绝、完整下载路径与失败清理均通过，但尚未跑过一次真实发布**，首次发布需确认 `publish-windows.yml` 的签名输入与 `relkey` 输出一致。

## 尚需目标机器验证

CI没有音频端点（audioAvailable=false），所以只验证音频API可执行、不可用时诚实报告，不能声称已验证真实音乐应用。真实Windows安装/卸载、系统托盘、混合DPI多屏、用户输入法/音乐应用、真实登录与长期性能仍需目标机器验收。本轮Mac锁屏，最后的目视检查未完成。

预览安装包未使用Windows代码签名。GPU从Metal改为WebGL2，公式与素材一致，不承诺不同系统/显卡逐像素一致。
