# Windows 0.2.0 与 Mac 3.4.0 行为对照

以当前仓库 Source 为实现标准。素材和 Swift 文件未修改。此表区分移植实现、自动化验证与目标机器验收，不把跨平台像素完全相同作为已验证事实。

| 行为 | Windows 实现与验证 |
| --- | --- |
| 待机骨骼、呼吸、尾耳、眨眼、视线、撸猫、嘴型 | 导出原 PoseRig 权重、原图和参数布局，移植 CatMotion 与着色器；1,232 个初始参数与原 Swift 参考逐一比对。撸猫判定与 Mac 同为 `focus == nil && pose == .idle && 指针在头部区域 && 速度 > 12`；注视毛线球时不计为撸猫。持续被撸超过 0.8 且距上次超过 7 秒时说「呼噜呼噜…」。 |
| 连续动画 | 原16段动作 alpha VP9，锚点/移动时段保留；原版入口、循环、出口。实际解码全部帧验证支持尺寸及镜像下无可见像素裁切。 |
| 鼠标穿透 | 透明留白不吞点击：按画布 alpha 判定，且判定跟随**窗口相对光标位置**每帧重算——猫走路时窗口在静止的鼠标下滑动，不会触发 pointermove，只按 pointermove 重算会让整个 520×320 窗口在猫离开后继续吞点击。 |
| 拖动、双击、走路 | 拖动打断旧动作、落地回弹；原生 Windows 双击间隔；行走持续到主进程期限，多屏位置约束。窗口是固定 520×320、猫画在中心偏下，因此走动、拖动与屏幕移除后的归位都按**绘制轮廓**而非窗口边界约束：横向取全部 clip 两个锚点与全部 rig 姿势的最大伸展，纵向取地面以上的最大高度并按 PetLayout 的 `fontSize*2.4+6` 保留气泡头顶空间，其余留白允许溢出屏幕外。猫因此能走到屏幕左右边缘，也能被拖到屏幕上方——否则固定窗口会让猫进不去屏幕顶部 137–235px 的区域。 |
| 玩球 | 独立透明可拖拽毛线球，原物理参数、追逐距离、视频球/真实球交接、抛掷后再玩、玩累后休息。 |
| 作息与陪伴 | 原日夜阈值、6点换日问候、休息提醒、自动睡眠/回来唤醒、锁屏；键盘节奏与播放速率、音频活动8秒进入/4秒退出。 |
| 菜单与台词 | 托盘菜单条目与 Mac 一一对应：摸摸 / 打招呼、现在散步、伸个懒腰、打个哈欠、丢个毛线球、让奶灰睡觉（睡着时为叫醒奶灰，单项切换）、自由走动 / 作息 / 陪伴三个勾选项、猫咪大小（迷你 72 / 小巧 100 / 标准 130 / 大只 170）、AI 额度与任务…、刷新 AI 额度、把奶灰叫回来（放回屏幕底部贴地并打招呼）、更新（进行中显示禁用的「正在检查更新…」/「正在更新…」）、操作提示行、退出。手动动作与三个陪伴开关都带原台词。 |
| 气泡与 AI 徽章 | 气泡宽度包住文字、贴在头顶上方 3px、字号按 `min(13, max(10, 猫高×0.1))` 缩放、带阴影与弹入动画，时长由调用方指定（默认 2.5 秒）。AI 徽章按绘制轮廓定位在猫的左下角，随尺寸移动；有任务进行时显示 `AI⋯`，tooltip 带未读条数。 |
| 系统感知 | 本地 Windows helper，仅发送距上次按键时长/音频活动/进程启动时间；不发送键值或音频。设备不可用时明确报告，不能伪装为可用。 |
| Codex/Claude 额度 | 固定官方接口、Desktop缓存→CLI→OAuth、账号隔离、限流、超时、单独续期检查、历史读数缓存。CLI会启动原客户端并可能续期，须设置中明确开启。详见quota-sources.md。 |
| 提醒 | 原阈值、耗尽、重置、显式会话等待/结束，8/15秒展示节流，过期/账号切换过滤；夜间时段、暂停、按提供方和事件静音；近期历史。标题为「提供方 · 窗口名」，100% 说「额度已用完。」、80% 说「已用 N% 额度。」、重置说「额度已重置。」，正文一律附带重置时间（与卡片的倒计时偏好无关，固定用绝对形式）。 |
| 面板 | 猫下方横版，点击外部收起，任务摘要。每个提供方带状态行（已连接/已过期/需登录/未授权/暂不支持/更新失败/未连接/更新中…）。主额度窗口按 `isExtra` 区分，其余计入「另有 N 个额度窗口，可在设置查看」。剩余 ≤10% 红、≤20% 橙、其余绿，进度条与数字同色；未知与不限额为灰色空条，不显示不确定态动画；过期数据整列转灰并显示「历史记录 · N 分钟前」与来源说明，新鲜数据把确认时间放在表头 tooltip。设置页包含全部额度窗口（extra 带「其他 · 」前缀）、来源与「最近确认 / 历史记录」区分、状态名、任务证据、最近提醒、预览气泡与单个暂停/恢复切换。 |
| 更新进度 | 与 Mac 明确不同：Mac 的更新包约 10 MB，点完几秒就换好，全程静默；Windows 安装包 121 MB，慢网络下要几分钟到几十分钟，静默等同于死机。下载期间每 700ms 刷新气泡「正在下载新衣服… N%」并同步写入托盘 tooltip（气泡会消失，tooltip 不会），失败时把 tooltip 恢复成待更新提示。 |
| 更新提示 | 自动检查发现新版本时说「有新衣服啦～ x.y.z，菜单里点一下就换」，与 Mac 同为 6 秒；同时写入托盘 tooltip 并在菜单显示「换上新衣服 · x.y.z」，开启系统通知时另发一条通知。 |
| 更新 | 按Windows安装包SemVer判断，独立于Mac版本；每日检查，用户确认后下载并启动安装器。与 Mac 一样要求发布者签名：用内置的同一把 Ed25519 公钥验证 `SHA256SUMS.txt.sig`，验签通过后才采信清单里的 SHA-256，再校验安装包。缺少签名资产的发布不会被提供为更新。渠道上与 Mac 不同：Windows 仍在预览渠道，显式接受 GitHub prerelease 发布，否则现有发布收不到更新提示。 |
| 默认值 | 猫咪大小默认「小巧」（100），保存过已废弃尺寸的设置迁移到最接近的合法档位；重置时间默认绝对日期，倒计时需在设置开启；系统通知、提醒声音默认关闭，提醒动作默认开启；自由走动、作息、陪伴默认开启；每日免打扰默认关闭。与 `AISettings` 及 `PetLayout.defaultHeight` 一致。 |

## 明确的平台适配

- Windows GPU 使用 WebGL2，Mac 使用 Metal。相同原图/权重/公式不意味着每台显卡逐像素完全一致。
- Mac 的桌宠窗口就是猫的大小，Windows 用固定 520×320 的透明窗口把最大尺寸的最宽一帧装下。因此气泡位置、AI 徽章位置和走动边界都由绘制轮廓换算，而不是直接取窗口边界；窗口可以延伸到屏幕外，只有轮廓受约束。
- Mac 钥匙串不可能直接复制到 Windows。Windows 支持当前文件登录来源；没有对应文件的 Windows Credential Manager 登录仍需原客户端提供支持。Claude 需要重新登录时，Windows 没有 Mac「允许钥匙串访问」的对应操作，只能回原客户端登录。
- Claude Desktop 只使用经实现的 `%APPDATA%/Claude` 缓存布局；未知 MSIX 布局不猜路径和账号。
- Mac 的更新签名覆盖安装包本体。Windows 安装包上限 512 MiB，Node 没有流式验签接口，因此签名覆盖 `SHA256SUMS.txt`，安装包的 SHA-256 只从这份已验签的清单读取。发布时需在发布机上用 `Tools/relkey` 对规范化的清单签名，私钥不进 CI。
- 真实用户账号、实际音乐应用、输入法、混合DPI多屏和长时间运行，需要目标Windows机器验收；CI没有音频设备时不能代替真实音乐验证。

## 验证

Node 142 项测试覆盖动画数学、实际解码边界、主进程IPC、动作取消竞态、Windows双击时序、作息、感知协议、会话证据、额度来源、提醒文案与去重、额度窗口分级、托盘菜单条目与状态、走动边界、更新签名与下载安全。Electron smoke 检验画布持续变化、16段透明动作、完整招手、连续走路超过旧4圈限制。Windows CI另编译本地helper并测试持续传感器协议与进程身份，再构建NSIS/ZIP并运行打包程序。

面板与设置页是渲染进程 DOM，自动测试只覆盖其数据来源（快照字段、`isExtra` 分级、提醒文案），配色档位与排版仍需目标机器目视确认。
