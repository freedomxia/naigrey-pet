# 奶灰桌宠 Implementation Plan

Goal: 将用户提供的灰白猫六姿态图做成可在当前 Apple Silicon Mac 运行的桌宠。
Architecture: Swift AppKit 无边框透明 NSPanel，六姿态透明图集，单个主线程状态机。菜单栏与右键共享操作；本地 UserDefaults 保存大小、位置和散步偏好。
Tech Stack: Swift 6 toolchain, AppKit, CoreGraphics, macOS 13+.
Spec: 用户已确认的本会话方案：透明桌宠、眨眼/哈欠/睡眠/走动、拖拽、点击招手、右键大小/暂停/退出，交付 app 和源码。

- [x] 素材：imagegen 处理透明图集，核查 alpha 和六格内容；图集复制到 app Resources。
- [x] Source/Sprites.swift：加载资源、按三列两行读取六姿态，透明区域裁切仅用于应用绘制。
- [x] Source/main.swift：透明悬浮窗口、状态机、轻微呼吸动画、点击拖动、屏幕约束、多显示器恢复、菜单及本地偏好。
- [x] build.command：swiftc 编译、生成 Info.plist、本地 ad-hoc 签名；失败立即退出。
- [x] 验收：加载六帧和 alpha、边界约束、app 实际启动、UI 截图检查、菜单状态/大小、退出重启恢复。拖动自动化受工具限制，详见验收记录。
- [x] 交付：源码、.app、使用说明及 zip；明确姿态动画与逐帧行走的差异。
